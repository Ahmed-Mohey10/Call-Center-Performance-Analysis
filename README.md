# Call Center Performance & Customer Sentiment Analysis Dashboard

## Project Overview

This project presents an interactive Microsoft Excel dashboard designed
to analyze call center performance, customer sentiment, and
response-time metrics. It brings key operational indicators together in
one view to help users explore trends and identify opportunities to
improve customer service.

## Dashboard Highlights

-   **Inbound Calls:** Displays the total inbound call volume and
    compares communication channels, including Call Center, Chatbot,
    Email, and Web.
-   **Call Center Comparison:** Compares call volumes across Baltimore,
    Chicago, Denver, and Los Angeles.
-   **Customer Sentiment:** Summarizes Very Positive, Positive, Neutral,
    Negative, and Very Negative feedback.
-   **Reasons for Calls:** Highlights common contact reasons, including
    billing questions, payments, and service outages.
-   **SLA Response-Time Analysis:** Tracks responses within SLA, below
    SLA, and above SLA.
-   **Geographical View:** Shows the distribution of activity across
    U.S. states.
-   **Interactive Filters:** Includes filters for call day and call
    center to support focused exploration.

## Tools & Techniques

-   Microsoft Excel
-   Pivot Tables
-   Pivot Charts
-   Dashboard design and data visualization
-   KPI monitoring and comparative analysis

## Key Metrics Shown

-   Total inbound calls
-   Calls by communication channel
-   Calls by call center
-   Customer sentiment distribution
-   Call reasons
-   Response-time / SLA categories
-   Response-time comparison by call center

## Purpose

The goal of this dashboard is to make call center data easier to
understand, monitor service performance, and surface patterns in
customer sentiment and response times.

## How to Use

1.  Download the Excel workbook from this repository.
2.  Open it in Microsoft Excel.
3.  Use the dashboard filters to explore call days and call center
    locations.
4.  Review the charts and KPIs to compare call volumes, sentiment, call
    reasons, and SLA performance.
